# QA Testing

- Write a test plan from the acceptance criteria before testing.
- Unit tests for logic, UI/widget tests for key screens, and an
  integration test for the main flow.
- Test edge cases: empty, huge values, invalid input, offline, slow
  network, interrupted actions.
- Report bugs with steps to reproduce, expected vs actual.
