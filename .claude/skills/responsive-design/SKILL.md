# Responsive Design

- **Mobile-first** – base styles for small screens, add `min-width`
  breakpoints.
- **Test widths** – 320, 375, 768, 1024, 1440 px.
- **Fluid layouts** – flex / grid, `%`, `rem`, `clamp()`; no fixed widths
  that overflow.
- **Responsive images** – `srcset` / `sizes` or framework image
  component; set width/height or aspect-ratio.
- **No horizontal scroll** at any width (tables scroll inside a wrapper).
- **Zoom** – usable at 200% zoom; text reflows.
- Touch targets ≥ 24 px; hover is never the only way to do something.
