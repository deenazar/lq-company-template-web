# Feature Docs

## docs/FEATURES.md
One section per feature with:
- What it does
- Screens
- User flow
- Business rules
- Data stored
- Validations
- Edge cases
- Status (Planned / In progress / Done)
- Date
- PR link

## CHANGELOG.md
One entry per PR, grouped as Added / Changed / Fixed / Security.

## docs/DECISIONS.md
One entry per decision: date, decision, options considered, reason.
